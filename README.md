# Economía Study

Centro interactivo de estudio para el segundo parcial de Economía.

## Incluye

- Seis módulos basados en los materiales de clase.
- Preguntas de opción múltiple y verdadero/falso.
- Explicación inmediata después de cada respuesta.
- Tarjetas de memoria con animación.
- Repaso rápido de 10 preguntas.
- Simulacro completo de 20 preguntas.
- Buscador de temas y preguntas.
- Favoritos para módulos y preguntas.
- Biblioteca de guardados para volver a los temas difíciles.
- Progreso, racha y mejor puntuación.
- Tema claro/oscuro.
- Navegación inferior optimizada para celular.
- Persistencia automática con `localStorage`.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Generar versión para Netlify

```bash
npm run build
```

En Netlify puedes subir la carpeta completa o conectar el repositorio con:

- Build command: `npm run build`
- Publish directory: `dist`

El archivo `netlify.toml` ya deja configurada esa información.
